A Programação Orientada a Objetos (POO) é um paradigma que organiza o software em
torno de objetos: entidades que reúnem dados (atributos) e comportamentos (métodos).
Este paradigma é hoje a base de grande parte do desenvolvimento profissional, porque
torna o código mais organizado, reutilizável e fácil de manter.
Este relatório documenta o desenvolvimento de um sistema de gestão para um hotel,
concebido em Python, no âmbito do Módulo 11 da disciplina de PSI do curso GPSI. O
sistema gere quartos de diferentes tipos (simples e luxo), hóspedes, funcionários com
diferentes funções e o cálculo da conta de estadia.
